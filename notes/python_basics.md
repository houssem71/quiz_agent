# Python basics

- A list is ordered and mutable: `[1, 2, 3]`.
- A tuple is ordered and immutable: `(1, 2, 3)`.
- A dictionary maps keys to values: `{"name": "Ada"}`. Keys must be hashable.
- `len(x)` returns the number of items in `x`.
- `range(5)` produces 0, 1, 2, 3, 4 (the end value is excluded).
- A function is defined with `def`, and returns `None` if it has no `return` statement.
- `is` checks identity (same object); `==` checks equality (same value).
